## Applying the coordination method locally

The trusted controller owns authorization, input selection, deterministic calculations, artifact pins, budgets, resource scheduling and durable state. The analyst proposes an evidence-bound interpretation. Two reviewers assess it independently. The controller validates syntax and evidence bindings, keeps disagreement or invalid output on HOLD, and routes the next bounded action to its authorized owner. Neither a model nor a pair of agreeing models can grant authority or certify an unsupported claim.

Keep protected source data, exact identity/time lookup and private receipts on the custodial side. Models receive only the specific permitted pack. Aggregate data can remain identifying; these prompts do not implement de-identification. Real health data forwarding is not enabled by this documentation.
