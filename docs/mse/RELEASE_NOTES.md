# MSE-001 repository import — 19 November 2026, Guam

## Purpose

The original complete MSE design and executable reference existed only as a
review package; GitHub held a coordination summary. This change preserves the
full package in `ctmansfield/mother` and supplies current, discoverable repository
documentation and reproducible verification.

## Contents

- Byte-preserved v0.1.0 release: 63 payload files and original manifest, covering
  all deliverables A–I, prototype code, evidence and three discrete patches.
- Current repository reconciliation, integration addendum and historical GADGET
  review with explicit dates and evidence scope.
- Installation, verification, rollback and change documentation, plus a root
  README entry point.
- A failure-propagating verifier and scoped GitHub Actions workflow. Contract
  verification requires `jsonschema==4.26.0`; runtime prototype remains stdlib-only.
- Repository context handoff bound to the publication instruction and report.

This import does not renumber or extend the v0.1.0 model. New observation,
glucose, graph, receptor and intervention interfaces described in the addendum
are proposals. No production ingestion, service, credential, dose, intervention
execution or Research Scout/Meta-Research schedule is changed.

## Verification and interpretation

See [the import report](IMPORT_REPORT_2026-11-19.md) for checks actually executed
for this publication. Original reports inside the preserved release retain their
original dates, test counts, failures, limitations and unmerged/undeployed scope.
New results must not be backfilled into those historical receipts.

The archived prototype has fixed, uncalibrated parameters and nominal intervals.
It can abstain and identify missing evidence. Passing its software tests does not
establish physiological observability, clinical accuracy or individual treatment
efficacy. The current glucose execution hold is preserved.
