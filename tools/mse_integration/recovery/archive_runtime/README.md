[Authorized build](https://github.com/ctmansfield/mother/pull/23#issuecomment-7056096916). This source set factors private values out of the scripts used during the initial build. The original private receipts bind executed bytes and actual dependencies. The normalized templates are syntax checked separately. Repeating full host boot or clean-room deployment from these templates has not been qualified. Backup/restore is owner-deferred.

## Ordered procedure

1. On the approved physical host use `archive_clone.py preflight` and `archive_clone.py define` with the same exact `--name`, `--seed`, `--seed-sha256`, `--host-pin`, `--boot`, `--uuid` and `--mac` inputs. Verify powered-off domain, standalone disk and no external devices before `virsh --connect qemu:///system start "$domain"`. An existing or mismatched target is a stop condition. Preserve the exclusive intent file and failed target instead of retrying over either.
2. Use the established private host transport and the exact guest's QGA channel. Ping before exec. For files use QGA file-open only after creating an exclusive 0600 file in a root-owned 0700 staging directory. Use bounded file-write chunks, flush/close, and verify exact guest SHA-256. For commands use guest-exec and poll guest-exec-status to a finite deadline. Check pinned domain UUID and guest boot or machine fingerprint before each operation. Private endpoints, source locations and credentials remain in restricted custody.
3. While the guest has only loopback, run `python3 -I -B guest_identity.py "$expected_seed_hostname" "$archive_hostname"` through QGA. Refuse inherited tailnet state, nonempty authorized keys, historical foreground stores or active SSH. Reboot only this owned guest through its agent. Verify the new hostname, generated machine and SSH host key fingerprints and unchanged NIC absence. Keep SSH off.
4. In the verified clone run `python3 -I -B guest_link.py "$reserved_mac" "$guest_cidr"`. On the host run `python3 -I -B host_link.py "$private_plan"`. The plan supplies `name`, `uuid`, `mac`, `host_pin`, `boot` and `bridge_cidr` from the approved values. The helper installs only bridge-owned host isolation, verifies the ordered rule classes, defines a no-forwarding libvirt link, then attaches the exact MAC to the stopped owned clone and starts it. Verify guest MAC/interface, exact IPv4 /30, absence of default route and no listeners. If necessary use `networkctl reload` and `networkctl reconfigure "$guest_interface"` in the clone to reconcile the network manager state. Leave phone ingress closed.
5. Transfer the verified wheels and FORGE r2 source artifacts into `/var/lib/phoenix-mse-archive-stage` through QGA. Run `python3 -I -B guest_dependencies.py wheel-pins.json "$guest_ip"`, then `python3 -I -B guest_package.py`. The dependency helper builds the private venv offline and verifies imports; the source helper rechecks every installed size/digest and runs the service entry point under the non-login identity without opening a listener.
6. Run `python3 -I -B guest_service.py "$private_guest_config" "$client_hostname" "$guest_interface"` once against the fresh owned layout. It creates a service-owned state parent and a mode-0700 child under it, generates the short-lived guest TLS inputs, initializes the pinned SQLite catalogs and starts the dedicated systemd unit. Retain private initialization/schema, TLS trust and installed source readbacks. Reruns must use `systemctl restart phoenix-mse-archive.service` without initialization. Allow a bounded listener readiness poll and verify an unchanged marker, hostname-verified HTTPS, wrong-name/plaintext denial, separate roles, exact retry/reopen and committed export readback. The local SQL/network inventory should show only the expected HTTPS listener.
7. Stage the host [relay unit](phoenix-mse-archive-relay.service) unloaded and check it with `systemd-analyze verify`. In its dedicated root supply private `guard.json` containing `host_pin` and `boot` and a mode-0600 `relay-config.json` containing `host`, `phone`, `guest_ip`, `bridge_ip`, `expiry` and `phone_enabled=false`. Run `relay_firewall.py check` before a separate owned start. The guard compares installed ordered kernel rules before the bound listener starts. Only the local host diagnostic source is allowed initially. Require a denied-source drop-counter increment, unchanged verified guest TLS chain and public/SQL absence. Enabling the exact phone peer and releasing its scoped grant are subsequent reviewed transitions. Keep TLS end to end. Do not enroll a clone using old identity material or route through a public endpoint.

## Stop, recovery and evidence

Stop the named relay first; inspect its owned nftables table, exact listener/sessions and retirement marker. Withdraw the phone handoff. Stop the named guest archive service via its systemd SIGINT path, preserve both SQLite databases, marker, config, TLS and evidence, and verify no associated listener. Shutdown of the exact guest is via its private agent after guest service stop. An interrupted or mismatched definition remains quarantined; no cleanup by path pattern or guessed PID.

## Startup dependencies

The guest unit is installed under `multi-user.target` and ordered after `systemd-networkd.service`. Before binding HTTPS, its `ExecStartPre` requires the one archive interface to reach networkd's routable state with IPv4 within 20 seconds. The unit binds the exact configured address. The MAC-matched static /30 in `/etc/systemd/network/05-phoenix-mse-archive.network` supplies that address with no default route. In networkd, a routable interface has a usable address and carrier. This readiness check does not add or require a gateway. Check the exact address, absence of IPv4 and IPv6 default routes, bound HTTPS listener and authenticated access to retained receipts and export. The archive unit has no dependency on the generic online target.

For an existing archive with the legacy unit, verify the exact installed unit digest privately, run `upgrade_guest_startup.py "$old_unit_sha256" "$guest_interface"` to verify the candidate, and record the candidate digest. After review, repeat with `--apply` and verify the installed digest and loaded dependencies. The updater leaves the running process in place until the controlled reboot.

To reproduce guest autostart after initial provisioning, enable the already-installed unit with `systemctl enable phoenix-mse-archive.service`. Reboot only the owned guest after reviewers finish. From the same pinned host boot, compare guest boot, machine and SSH key identities, package manifest, initialization marker, effective config, certificate, network configuration and unit before and after. Verify the archive starts through systemd and preserves the exact phone and diagnostic receipts and logical export. Use readback only for this check. Keep backup and restore outside this procedure.

The physical host must have the isolated libvirt network and its bridge filtering active before the guest starts. The archive domain and network have libvirt autostart disabled. The relay unit is linked under `/run/systemd/system` and its guard is bound to the approved physical host boot. The private relay requires the existing tailnet identity, the exact permitted addresses, unexpired config and the original guest TLS chain. A host reboot requires separately approved revalidation and restaging of those host dependencies before ingress. Do not use the fresh-clone procedure to recreate an existing owned domain or state directory.

Before the archive-specific wait was introduced, the controlled archive guest reboot brought up the static address before the generic `systemd-networkd-wait-online.service` reached its roughly two-minute timeout. After that job failed, systemd started the enabled archive unit automatically and the authenticated persistence checks passed. That earlier configuration took more than two minutes. Use the exact HTTPS listener and scoped GET results as the readiness checks. Ordinary guest service restart and an isolated identity reboot were tested separately. Host reboot, retained-host disaster recovery and full template replay remain unqualified.
