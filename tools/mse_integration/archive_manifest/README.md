# Evidence archive package verification

[MSE-EVIDENCE-INFRA-20261121-02 r1](https://github.com/ctmansfield/mother/pull/23#issuecomment-7056096916). This verifier checks an inert local ZIP or TAR against an independently prepared exact-source allowlist. It performs no extraction, build, installation, network operation, or secret review on the guest.

Supply a JSON array with one row per expected regular member. Each row has `member` (package path), `commit` (full 40-character Git commit), and `source` (path at that commit). Pin the allowlist digest in the build handoff. Include the exact dependency lock, migration files, startup/config templates, and applicable contract in the expected membership. Do not include runtime configuration, keys, credentials, machine/SSH identity, or database files. Generated outputs need a separate deterministic recipe and comparison before approval. Do not silently map generated bytes to a different tracked file.

```sh
python3 -B tools/mse_integration/archive_manifest/verify.py \
    --checkout /path/to/pinned/source \
    --package /path/to/first/source-package.zip \
    --repeat-package /path/to/second/source-package.zip \
    --allowlist /path/to/reviewed/source-allowlist.json
```

The result binds host-independent package bytes, exact source members, and allowlist digest. Matching inputs count as reproducibility evidence only with independent clean build receipts carrying identical environment and command pins. The check refuses unknown and nonregular package members and several obvious secret patterns. Review tracked content and container metadata independently. This is not proof of secret absence in inherited VM disks, environment, mounted directories, logs, compression metadata, or deployed artifacts.
